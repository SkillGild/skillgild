# Contributing to SkillGild

Thanks for helping improve [SkillGild](https://skillgild.dev). This repository is SkillGild's public community home. It does not contain the application source code or the contents of marketplace skills, so most contributions happen through issues.

## Ways to contribute

- **Report a bug** in the website, the `skillgild` CLI, the MCP connection or the API. Use the [bug report template](https://github.com/SkillGild/skillgild/issues/new?template=bug_report.yml).
- **Request a feature** or a new integration. Use the [feature request template](https://github.com/SkillGild/skillgild/issues/new?template=feature_request.yml). Check the [roadmap](https://skillgild.dev/docs/roadmap) first, since your idea may already be planned.
- **Improve this repository.** Pull requests that fix typos, broken links or unclear wording in the README and community files are welcome.
- **Publish a skill.** Skills are not contributed through GitHub. [Apply to become a creator](https://skillgild.dev/docs/creators) and publish through the Creator studio on skillgild.dev.

## Before you open an issue

1. Search [existing issues](https://github.com/SkillGild/skillgild/issues) to avoid duplicates.
2. Run `skillgild status` and include the relevant output, with anything personal removed.
3. **Never include** API keys (`sg_live_…`), tokens, passwords, private files or the contents of paid skills.

Questions about your account, billing or a specific skill's behaviour are better handled by the [support center](https://skillgild.dev/support) or [support@skillgild.dev](mailto:support@skillgild.dev). You can report a misbehaving skill from its listing page.

## Pull requests

1. Keep each pull request focused on one change.
2. Only link to pages that exist on skillgild.dev, and don't add claims the product doesn't support today.
3. Fill in the pull request template.
